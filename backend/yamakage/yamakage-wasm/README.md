# YAMAKAGE WebAssembly Engine

### Overview

This is the core terrain elevation and sun trajectory calculation engine for the YAMAKAGE API.
To maximize the processing speed of simulating tens of thousands of terrain data points, it is implemented in Rust and compiled to WebAssembly (Wasm). It runs on Cloudflare Workers (TypeScript).

### Setup

To develop and build the Wasm module, you need the following tools:

1. **Rust Toolchain**
Install `rustup` by following the instructions on the [official Rust website](https://www.rust-lang.org/tools/install).
2. **wasm-pack**
A build and packaging tool for WebAssembly. Install it using Cargo:
```sh
cargo install wasm-pack

```



### Commands

We recommend running the Wasm build process via the `pnpm` script in the parent directory (`backend/yamakage`).

#### Build (Recommended)

Running the following command in the parent directory builds the Wasm module and automatically removes the unnecessary `pkg/.gitignore` generated by `wasm-pack`.

```sh
# Run in the backend/yamakage directory
pnpm run build:wasm

```

#### Manual Build

You can also run `wasm-pack` directly in this directory. (*Note: Please manually delete the automatically generated `pkg/.gitignore` before committing.*)

* **Release Build** (Optimized for production)
```sh
wasm-pack build --target web

```


* **Debug Build** (For development)
```sh
wasm-pack build --dev

```



#### Test

Run unit tests for the pure Rust calculation logic.

```sh
cargo test

```

### Development Notes

**Regarding the `pkg/` directory in version control**:
Typically, the `pkg/` folder containing Wasm build artifacts is excluded from Git via `.gitignore`. However, to improve the stability and build speed of our CI/CD pipeline (GitHub Actions), we intentionally include the `pkg/` directory in Git.
Whenever you modify the Rust code, you must build it locally by running `pnpm run build:wasm` and commit the resulting changes in the `pkg/` directory along with your source code.
